# Tooling up for SharePoint Framework
There were AppParts and AppScript parts that had shortcomings.  SharePoint Framework resolves those issues.

Modern SharePoint pages can only be customized by the SharePoint Framework web parts.

SharePoint Framework Toolchain

- Node.js  
- npm  
- Yeoman \- for scaffolding code  
- Visual Studio Code (not a requirement)  
- TypeScript \- Open source language \- JavaScript superset that supports interfaces, static typing, supports to transition from server side development to client side scripting  
- Gulp \- build, packaging, deployment tool  
- Workbench \- development test tool to support local testing
