# Developer Monitor Resolution and Scaling

To maintain a productive and comfortable development workstation environment, here are some key settings that work well:

- **Monitor Resolution**: Opt for a monitor that is not 4K to avoid potential scaling issues and ensure better compatibility with development tools.
- **Screen Scaling**: Set the display scaling to 125% without using custom scaling, especially beneficial for laptop users.
- **Browser Zoom**: Use 90% zoom level in your web browser for optimal readability.
- **Windows Theme**: Enable the dark theme in Windows to reduce eye strain during long coding sessions.
